安装步骤

1
下载 vsix 文件
点击上方下载按钮，保存 moss-language-1.0.0.vsix 到本地。
2
打开 VSCode 扩展面板
按 Ctrl+Shift+X 打开扩展，点击右上角 ··· 菜单。
3
Install from VSIX
选择 Install from VSIX...，选中下载的 moss-language-1.0.0.vsix。
4
重启 VSCode
安装完成后重启 VSCode，打开任意 .moss 文件即可使用。
