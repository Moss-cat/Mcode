更新日志

MOSS 语言与赛事平台的版本更新记录，最新版本排在最前。

v1.0.0 当前版本 2026-10-06
MOSS 通用博弈语言正式版
  • 重大变更：MOSS 改为通用博弈语言，不再绑定囚徒困境。所有游戏规则由管理员的裁判代码定义。
  • 新增：choose() 接受任意值（如 "rock"、"all-in"），含义完全由裁判解释，可玩石头剪刀布、赌博等任意游戏。
  • 新增：裁判代码机制 —— 管理员发布赛事时编写隐藏评判代码，赛后自动执行，通过 P1/P2（dict：name/score/choices）裁定胜者与得分。
  • 新增：单败淘汰赛制 —— 随机配对，淘汰输的一半，奇数时额外踢掉最低分者，直到剩 1 人。
  • 新增：main() 中设置 final_choose="策略函数名" 指定参赛策略，无 main() 无法发布。
  • 新增：play(botA, botB, rounds) 内部对战训练，返回每轮双方选择，计分由 Bot 自行计算。
  • 修复：字典字面量 {} 解析、not in / is not 运算符。
  • 修复：choose() 现在相当于 return，调用后函数立即结束。
  • 新增：163 邮箱 SMTP 接入 —— mailer.js 导出 sendVerifyCode(to, code)；注册 / 找回密码 / 管理员与超管登录的验证码改为真实发信（HTML + 纯文本双版本，5 分钟有效，底部注明请勿回复）。
  • 新增：SMTP 授权码以摩斯密码变体密文存储，由 getSmtpPass() 还原；新变体支持大小写（段首 1=大写、0=小写），并修掉了点划互相污染的撞码问题。
  • 新增：发信防护 —— 同一邮箱 60 秒内限一次、同一 IP 每小时限 10 次；发信异步不阻塞请求，失败抛错并记录日志。
  • 新增：共享后端 server.js —— 用户 / 申请 / 赛事等数据落盘共享，超管可实时看到新申请（3 秒轮询）；后端缺失时自动退回纯本地模式。
  • 新增：data.json 以摩斯码形式落盘，文件无法直接阅读。
  • 新增：本更新日志页，以及网站内的文档阅读入口。
  • 修复：用 file:// 直接打开页面时的 ERR_BLOCKED_BY_CLIENT —— 非 http(s) 协议下自动跳过同步请求。
v0.9.0 历史版本 2026-10-05
插件下载页与赛事流程完善
  • 新增：VSCode 插件下载页，新手必装指引（下载 → Install from VSIX → 重启）。
  • 新增：邮箱验证码流程（注册 / 找回密码 / 管理员与超管登录）。
  • 新增：管理员发布赛事、玩家提交 Bot、系统随机匹配并运行对战。
v0.8.0 历史版本 2026-10-04
MOSS 语言与 VSCode 插件初版
  • 新增：MOSS 解释器（词法 / 语法 / 解释执行），沙盒限制步数与递归深度。
  • 新增：VSCode 插件 —— 语法高亮、编译检查、运行对战。
  • 新增：用户 / 管理员 / 超管三级账号体系，基于 localStorage 的数据层。
