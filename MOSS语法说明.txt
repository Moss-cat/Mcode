一、简介
------------------------------------------------------------
MOSS 是一门 Python 风格的编程语言，文件后缀为 .moss。
专为编写「囚徒困境」类博弈 AI Bot 设计。
玩家用 MOSS 编写策略，在竞技场中与其他 Bot 对战，
存活到最后或积分最高者获胜。

MOSS 代码示例（一报还一报策略）：

    # tit-for-tat.moss
    def main():
        if len(opponent_history) == 0:
            choose("cooperate")
        else:
            choose(opponent_history[-1])


二、基本语法
------------------------------------------------------------

2.1 注释
  使用 # 开头，整行为注释：
      # 这是一条注释
      choose("cooperate")  # 行尾注释也可以

2.2 缩进
  使用空格缩进表示代码块（4 个空格为标准），与 Python 一致。
  不支持用大括号 {} 表示代码块。

      def main():
          if win:
              choose("cooperate")
          else:
              choose("defect")

2.3 关键字
  if, elif, else, while, for, in, def, return
  True, False, None, and, or, not, is
  pass, break, continue

  特殊关键字（事件钩子）：
  run ... when ...:
      run "事件名" when 条件:
          代码块

六、函数
------------------------------------------------------------

6.1 定义
      def 函数名(参数1, 参数2):
          函数体
          return 返回值

  示例：
      def add(a, b):
          return a + b

      result = add(3, 4)  # 7

6.2 main() 函数
  MOSS 程序必须定义 main() 函数，引擎每轮自动调用它。
  main() 内应调用 choose() 做出本轮决策。

      def main():
          choose("cooperate")


七、博弈专用语法
------------------------------------------------------------

7.1 choose(option)
  在 main() 内调用，做出本轮选择。
  option 必须是 "cooperate"（合作）或 "defect"（背叛）。

      def main():
          choose("cooperate")   # 合作
          # choose("defect")    # 背叛

7.2 只读变量（引擎每轮注入）
  win          上一轮是否赢（bool），第一轮为 False
  round        当前轮数（int，从 0 开始）
  history      自己的决策历史（list）
  opponent_history  对手的决策历史（list，1v1 模式）

  注意：这些变量只读，不能赋值，否则报错。

      def main():
          if len(opponent_history) == 0:
              choose("cooperate")
          elif opponent_history[-1] == "defect":
              choose("defect")
          else:
              choose("cooperate")

7.3 delay(秒)
  延迟函数，用于模拟思考时间，不影响实际决策结果。

      def main():
          delay(0.5)
          choose("cooperate")

7.4 run "事件名" when 条件:
  事件钩子，当条件成立时执行代码块。

      def main():
          choose("cooperate")

      # 上一局输了就打印日志
      run "on_loss" when not win:
          print("上一局输了，总结教训")

十、囚徒困境计分规则
------------------------------------------------------------
标准 PD 计分矩阵：

              对手合作    对手背叛
  我合作       +3 (R)      +0 (S)
  我背叛       +5 (T)      +1 (P)

  T = 5  背叛对方合作
  R = 3  双方合作
  P = 1  双方背叛
  S = 0  合作被背叛

多轮累计积分，积分最高者胜。


十一、完整示例
------------------------------------------------------------

11.1 一报还一报（tit-for-tat）
      def main():
          if len(opponent_history) == 0:
              choose("cooperate")
          else:

11.2 永远合作
      def main():
          choose("cooperate")

11.3 永远背叛
      def main():
          choose("defect")

11.4 随机
      def main():
          if randint(0, 1) == 0:
              choose("cooperate")
          else:
              choose("defect")

11.5 冷酷触发（grim-trigger）
      def main():
          betrayed = False
          for c in opponent_history:
              if c == "defect":
                  betrayed = True
                  break
          if betrayed:
              choose("defect")
          else:
              choose("cooperate")

11.6 赢存输改（pavlov）
      def main():
          if len(history) == 0:
              choose("cooperate")
          elif win:
              choose(history[-1])
          else:
              if history[-1] == "cooperate":
                  choose("defect")
              else:
                  choose("cooperate")


十二、沙盒限制
------------------------------------------------------------
为保证安全，MOSS 解释器有以下限制：
  - 无 import / open / eval / exec，不能访问文件或网络
  - 单轮最大执行步数 100,000（防止死循环）
  - 最大递归深度 200
  - win / round / history / opponent_history 为只读
  - 编译或运行出错时，本轮默认 choose("defect")
  - choose() 参数必须是 "cooperate" 或 "defect"，否则本轮默认 defect
