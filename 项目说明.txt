一、项目概述
------------------------------------------------------------
本项目是一个在线编程博弈赛事平台，前端为 HTML + CSS + JavaScript，
包含用户系统、管理员系统、超管系统，以及一门自定义编程语言 MOSS
（后缀 .moss），玩家用 MOSS 编写 AI Bot 在囚徒困境博弈中对战。

数据层以浏览器 localStorage 为主；可选配套 Node 后端（server.js）
用于跨设备数据同步与邮箱验证码发送（mailer.js，163 SMTP）。
直接用 file:// 打开时自动降级为纯本地模式，无需后端即可运行；
也可部署到 GitHub Pages 等静态托管平台（前端独立可用）。

三、MOSS 语言语法
------------------------------------------------------------
MOSS 是 Python 的变体，专为编写博弈 AI Bot 设计。

【与 Python 一致】
  - 控制流：if / elif / else、while、for ... in
  - 函数定义：def 函数名(参数):
  - 数据类型：list（列表）、dict（字典）、tuple（元组）
  - 运算符：+ - * / % // ** == != < > <= >= and or not
  - 注释：# 开头

【特殊语法】
  main()
      程序必须定义 main() 函数，引擎每轮调用它取决策。

  choose("cooperate")  或  choose("defect")
      在 main() 内调用，做出本轮选择。
      参数必须是 "cooperate" 或 "defect"。

  win（只读变量）
      上一局是否赢（bool）。第一轮为 False。

  round（只读变量）
      当前轮数（从 0 开始）。

  history（只读列表）
      自己每轮的决策历史。

  opponent_history（只读列表）
      对手每轮的决策历史（1v1 模式）。

  delay(秒)
      延迟函数，用于模拟思考时间，不影响实际决策。

  run "事件名" when 条件:
      事件钩子，条件成立时执行后续代码块。
      例：run "on_loss" when not win:  print("上局输了")

六、囚徒困境计分规则
------------------------------------------------------------
标准囚徒困境（PD）计分矩阵：

              对手合作    对手背叛
  我合作       +3 (R)      +0 (S)
  我背叛       +5 (T)      +1 (P)

  T = 5  背叛对方合作（诱惑）
  R = 3  双方合作（奖励）
  P = 1  双方背叛（惩罚）
  S = 0  合作被背叛（ sucker 收益）

多轮累计积分，积分最高者胜。


七、使用方法
------------------------------------------------------------
【本地运行】
  在项目目录启动任意静态服务器，例如：
    python -m http.server 8000
  然后浏览器打开：
    http://localhost:8000/moss-arena.html   ← MOSS 博弈竞技场
    http://localhost:8000/                   ← 主站（登录/注册）

【MOSS 竞技场】
  1. 左侧代码编辑器可加载 6 个示例 Bot：
     - tit-for-tat    一报还一报（经典强策略）
     - always-cooperate  永远合作
     - always-defect     永远背叛
     - random         随机
     - grim-trigger   冷酷触发（被背叛一次后永远背叛）
     - pavlov         赢存输改
  2. 右侧选择对手 / 轮数，点击「开始对战」
  3. 支持 1v1 对决 和 多人混战（round-robin）两种模式

【编写自己的 Bot】
  在编辑器中写 MOSS 代码，必须包含 main() 并调用 choose()。
  示例（tit-for-tat）：
      def main():
          if len(opponent_history) == 0:
              choose("cooperate")
          else:
              choose(opponent_history[-1])

  无需用户重新设置密码。

十、安全沙盒
------------------------------------------------------------
MOSS 解释器内置沙盒限制：
  - 无 import / open / eval / exec
  - 单轮最大执行步数 100,000（防死循环）
  - 最大递归深度 200
  - win / round / history / opponent_history 为只读变量，禁止赋值
  - 编译错误或运行时错误时，本轮默认 choose("defect")
